
# Project Blueprint

## Overview

This project will create a drag-and-drop interface using Next.js and Shadcn UI. The interface will be a simple "Kanban" style board with columns and draggable items.

## Features

*   **Drag-and-Drop:** Users can drag and drop items between columns.
*   **Kanban Board:** A visually organized board with columns for different stages of a workflow.
*   **Shadcn UI:** The user interface will be built using Shadcn UI components for a modern and clean look.
*   **Responsive Design:** The layout will be responsive and work on different screen sizes.

## Current Plan

1.  **Install Dependencies:** Install `@dnd-kit/core`, `@dnd-kit/sortable` and the necessary Shadcn UI components.
2.  **Create Components:**
    *   Create a new page for the drag-and-drop feature at `/dnd`.
    *   Create a "Kanban" board component.
    *   Create components for columns and tasks.
3.  **Implement Drag and Drop:** Use `dnd-kit` to handle both horizontal (columns) and vertical (tasks) drag-and-drop logic.
4.  **Style with Shadcn UI:** Use Shadcn UI components to build the interface.
5.  **Final Polish:** Review the code, add comments, and ensure everything is working correctly.
